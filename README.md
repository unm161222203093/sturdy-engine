
# KEERTHANA E - WOMEN SAFETY ALERT WEBSITE

## 1. Project Title
Women Safety Alert Website

## 2. Project Description
The Women Safety Alert Website is a web-based application
developed to support women's safety. It provides a simple
and user-friendly interface with family contact management,
current location access, and a police siren sound feature.

The main purpose of this project is to help users quickly
access trusted family contacts, view their current location,
and play a siren sound when needed.

## 3. Objectives
- To develop a simple and user-friendly safety website.
- To allow users to add and manage family contacts.
- To display the user's current location.
- To provide a police siren sound feature.
- To demonstrate the use of HTML, CSS, and JavaScript
  in a safety-related web application.

## 4. Main Features

### 4.1 Home Page
The home page displays the project name, welcome message,
and safety-related information.

### 4.2 Family Contacts
Users can add family members' names and phone numbers.
They can view saved contacts, call a contact, and remove
contacts when required.

### 4.3 Current Location
The location feature uses the browser's Geolocation API
to obtain the user's current coordinates after permission
is granted. Users can view the location on Google Maps.

### 4.4 Police Siren Sound
The website includes a button to play a police siren sound.
This feature provides an audible alert when activated by
the user. The sound feature does not automatically contact
the police or send an emergency message.

## 5. Technologies Used
- HTML - Web page structure
- CSS - Website styling and layout
- JavaScript - Interactive website functions
- Geolocation API - Accessing device location with permission
- Google Maps - Viewing location coordinates
- Audio - Playing the siren sound

## 6. Software Requirements
- Windows computer or compatible device
- Visual Studio Code
- Google Chrome or another modern web browser
- Live Server extension (optional)
- Internet connection for online map access

## 8. How to Run the Project
1. Download or clone the project from GitHub.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server or a local web server.
4. Allow location permission when prompted.
5. Add family contact details and test the contact options.
6. Click the siren button to test the sound feature.

## 9. Advantages
- Simple and easy-to-use interface.
- Allows users to manage trusted family contacts.
- Provides access to current location.
- Offers a user-activated siren sound.
- Demonstrates practical web development skills.

## 10. Limitations
- Family contacts are stored in the browser on the
  current device.
- Location access requires user permission.
- The siren sound does not guarantee that nearby people
  will hear it.
- The website does not automatically alert family members
  or contact police.
- Location and sound features depend on browser and
  device support.

## 11. Future Enhancements
- Secure user registration and login.
- Emergency message feature for trusted contacts.
- Secure database integration.
- Optional location sharing with trusted contacts.
- Improved accessibility and mobile-friendly design.

## 12. Conclusion
The Women Safety Alert Website is a student project
that demonstrates how web technologies can provide
useful safety-related features. It combines family contact
management, location access, and a police siren sound
in one interface. The project can be enhanced in the
future with secure communication and additional features.
